# Generic diagnostics function for multilevelcoda

This is a generic function for diagnostics methods in multilevelcoda.
See
[`diagnostics.complr`](https://florale.github.io/multilevelcoda/reference/diagnostics.complr.md)
for the method for
[`complr`](https://florale.github.io/multilevelcoda/reference/complr.md)
objects.

## Usage

``` r
diagnostics(x, ...)
```

## Arguments

- x:

  An object to calculate diagnostics, primarily around extreme values
  and assumed distributions.

- ...:

  Additional arguments passed to methods.

## Value

`diagnostics` class object
